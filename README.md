# 売れ残り帳

## 説明

1. 商店街の和菓子店を手伝う私は、閉店後に売れ残りを数える場面で、ノートへの書き写しに 20 分かかり、翌朝、父が字を読めずに電話してくることに困っている。
2. 似たものに在庫の管理アプリがあるが、お菓子の名前を毎回打ち込むのが面倒で、父がスマホの小さな字を読まないから広がっていない。
3. 今は AI でノートの写真から数を読み取れるようになったので、写真を撮るだけで、父が読める大きな字の表と、翌日に作る数の目安が出る道具を作る。

## 使う人と場面

閉店後、店の奥で、父がスマホで、あすの目安を読む。

## 手元での動かし方

このリポジトリにあるのは `index.html` 1 枚だけで、部品(ライブラリ)の取り込みも、サーバーも要りません。

1. このフォルダをパソコンかスマホに置く。
2. `index.html` をブラウザ(Safari、Chrome など)で開く。パソコンならファイルを 2 回押せば開く。
3. 「きょうの売れ残り」で、お菓子ごとに「作った」の欄にその日作った数を入れ、−・＋で売れ残りの数を入れる。
4. 翌日が雨なら「あすは雨」を押す。
5. 父が目安と違う数にしたいときは、「あすの目安」の「父の数」を −・＋ で直す。直したお菓子には、道具の目安との差(＋2 など)が出る。
6. 「父に送る」を押すと、大きな字で「あすの目安」が出る。数は父の数で、父が直したお菓子だけ道具の目安を小さく添える。スマホなら「文章で送る」で、文章にして送れる。
7. 「父に送る」を押すと、その日の分が、いちばん下の「これまでの記録」に残る。送った日、作る日、お菓子ごとの道具の目安と父の数が残り、何日ぶんあるか、父が直した回数、道具の目安との差の合計も出る。同じ日に押し直すと、その日の分を書き直す。
8. 目安の出し方を変えたいときは、「父の決まり」で、四角の数を直す。直すとすぐ、あすの目安が変わる。

入れた数は、開いたブラウザの中に保存されます。別の端末やブラウザには引き継がれません。
日付の区切りは昼の 12 時です。12 時までは前の日の続きとして数が残り、12 時を過ぎて開くと、売れ残りは 0、雨の印はなし、父の数は道具の目安と同じ、から始まります(作った数と、父の決まりの数は、前回の数を引き継ぎます)。
「これまでの記録」は、12 時の区切りでは消えません。はじめは空っぽです。

## いまできること・まだのこと

- できる: 売れ残りと作った数の入力、あすの目安の計算、大きな字の表、文章で送る、12 時区切りの日付の切り替え、「父の決まり」を画面に並べて数を直す(①〜⑧を上から順に当てはめる)、あすの目安を父の数に直す、「父に送る」を押した日ごとに道具の目安と父の数を残して「これまでの記録」で見返す。
- まだ: 写真から数を読み取る仕組み。「写真を撮る」のボタンは置いてありますが、押すと「準備中です」と出るだけです。

## 架空の例について

このリポジトリに出てくるお店の様子、お菓子の名前、作った数、売れ残りの数、目安の決まりは、すべて架空の例です。実在のお店や数字ではありません。
